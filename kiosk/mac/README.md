# 맥 노트북 전시 잠금 안내

과제전에서 관람객이 hueman 말고 다른 것을 열지 못하게 하는 방법입니다.
맥에는 "앱 하나만 쓰게 잠그기" 기능이 없어서, 아래 네 가지를 겹쳐서 막습니다.

| 단계 | 막아 주는 것 | 파일 |
| --- | --- | --- |
| 1. 전시 전용 맥 계정 | 내 파일·사진·카톡·메일·알림이 보이는 것 | 없음 (시스템 설정) |
| 2. 크롬 잠금 프로필 | 다른 사이트 접속, 시크릿 창, 개발자 도구, 노트북에 다운로드 | `hueman-chrome-lock.mobileconfig` |
| 3. 키오스크 실행기 | 주소창·탭·메뉴, 화면 꺼짐·잠자기, 스와이프 뒤로 가기 | `hueman-kiosk.command` |
| 4. 키보드 덮개 | Cmd+Q, Cmd+Tab 같은 단축키로 빠져나가기 | 아크릴판·두꺼운 종이 |

hueman은 **트랙패드·마우스 클릭만으로 처음부터 끝까지 진행**되니 키보드는 덮어도 됩니다.
노트북 덮개를 닫으면 **카메라도 꺼지므로** 덮개는 열어 두세요.

## 1. 전시 전용 맥 계정 만들기 (가장 중요)

1. 시스템 설정 → 사용자 및 그룹 → **사용자 추가**
2. 유형은 **일반**(관리자 아님), 이름은 예: `hueman 전시`
3. 그 계정으로 로그인해서 아래 2~3단계를 진행합니다.

관람객이 단축키로 빠져나가더라도, 이 계정에는 내 파일·로그인된 앱·알림이 없습니다.
2단계 프로필은 **설치한 계정에만** 적용되므로 평소 쓰는 내 계정의 크롬은 그대로입니다.

## 2. 크롬 잠금 프로필 설치 (전시 계정에서)

1. Google Chrome을 설치합니다(응용 프로그램 폴더).
2. `hueman-chrome-lock.mobileconfig`를 더블클릭합니다.
3. 시스템 설정 → 개인정보 보호 및 보안 → **프로파일**(macOS 버전에 따라 일반 → 기기 관리)에서 "hueman 전시용 크롬 잠금"을 **설치**합니다. 관리자 암호를 물으면 내 계정 암호를 넣습니다.
4. 크롬을 완전히 껐다가 다시 켭니다.

적용 확인: 크롬에서 `google.com`을 열면 **"관리자가 차단함"** 화면이 떠야 합니다. hueman 주소는 열려야 합니다.

이 프로필이 하는 일:

- `https://dhoklim.github.io/hueman`과 QR·감정 벽 서버(`hueman-photo-transfer.dhoklim-bdd.workers.dev`) **외의 모든 주소 차단**
- hueman 사이트의 **카메라를 묻지 않고 허용**
- 시크릿 창·게스트·새 크롬 프로필·크롬 로그인·개발자 도구 끄기
- 다운로드 막기 (결과 카드는 관람객이 QR로 폰에 받아 감)

관람객 휴대폰에는 아무 영향이 없습니다. QR은 각자 폰 브라우저에서 열립니다.

## 3. 키오스크 실행기

1. `hueman-kiosk.command`를 더블클릭합니다.
   - 처음에 "확인되지 않은 개발자" 경고가 뜨면 **우클릭 → 열기 → 열기**를 누릅니다.
   - 실행 권한 오류가 뜨면 터미널에서 한 번 실행합니다: `chmod +x hueman-kiosk.command`
2. 크롬이 주소창·탭 없이 전체화면으로 hueman 대기 화면을 띄웁니다. 뒤에 남은 터미널 창은 닫아도 됩니다.
3. 처음 한 번은 macOS가 "Google Chrome이 카메라에 접근하려고 합니다"를 물을 수 있습니다. **허용**을 누르세요.
   (시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 Google Chrome이 켜져 있어야 합니다.)

크롬이 켜져 있는 동안은 맥이 잠들거나 화면이 꺼지지 않습니다.
끝낼 때는 키보드 덮개를 들고 **Cmd+Q**를 누릅니다.

## 4. 전시 당일 체크

- [ ] 전시 계정으로 로그인했는가
- [ ] 충전기 연결, 볼륨 확인
- [ ] 와이파이 연결 (작품은 인터넷으로 불러옵니다)
- [ ] `hueman-kiosk.command` 실행 → 끝까지 한 번 플레이 → QR을 폰으로 찍어 사진이 오는지 확인
- [ ] 키보드 덮개, 노트북 덮개는 열어 두기
- [ ] 카메라 앞에는 한 명씩 서도록 안내

갤러리(관람객이 남긴 결과 카드)를 비우고 시작하려면, 실행기를 띄우기 전에 전시 계정의 `~/hueman-kiosk-profile` 폴더를 지우면 됩니다. 전시 전용 크롬 프로필이 통째로 새로 만들어집니다.

## 전시가 끝나면

1. 시스템 설정 → 개인정보 보호 및 보안 → 프로파일에서 "hueman 전시용 크롬 잠금"을 **제거**
2. 필요 없으면 시스템 설정 → 사용자 및 그룹에서 전시 계정을 삭제

## 한계

- Cmd+Option+Esc(강제 종료)·전원 버튼 같은 동작은 소프트웨어로 완전히 막을 수 없습니다. 그래서 1단계(전시 전용 계정)와 키보드 덮개가 중요하고, 가끔 자리를 확인해 주세요.
- 진짜 "앱 하나 잠금"이 필요하면 iPad의 **사용법 유도 모드(Guided Access)**가 가장 확실합니다. 설정 → 손쉬운 사용 → 사용법 유도 모드.
